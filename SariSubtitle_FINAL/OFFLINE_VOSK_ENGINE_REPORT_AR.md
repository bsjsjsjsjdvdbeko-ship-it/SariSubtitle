# تقرير دمج محرك التفريغ المحلي — Sari Subtitle

## ما أضيف إلى المشروع
- مكتبة Android الرسمية `com.alphacephei:vosk-android:0.3.47`.
- `VoskModelManager.kt`: تنزيل النماذج بطلب المستخدم، عرض التقدم، استخراج آمن يمنع Zip Slip، والتحقق من وجود ملفات النموذج قبل اعتباره مثبتاً.
- `OfflineVoskTranscriber.kt`: فك مسار الصوت من ملفات الوسائط عبر Android `MediaExtractor` و`MediaCodec`، تحويله إلى PCM أحادي 16kHz، ثم تمريره إلى Vosk محلياً وبناء ملف SRT من توقيت الكلمات عند توفره.
- خيار `Vosk محلي دون إنترنت` في إعدادات STT، وأزرار تنزيل النموذج العربي أو الإنجليزي.
- إذا فشل مزود سحابي وكان نموذج Vosk الموافق للغة مثبتاً، يجرب التطبيق المحرك المحلي تلقائياً. وإذا اختير Vosk مباشرة فلا يحتاج إلى مفتاح API ولا يرفع الصوت إلى خادم.

## النماذج
- العربية: `vosk-model-ar-mgb2-0.4`، نحو 318MB تنزيل، من فهرس Vosk الرسمي، ترخيص Apache 2.0.
- الإنجليزية: `vosk-model-small-en-us-0.15`، نحو 40MB تنزيل، من فهرس Vosk الرسمي، ترخيص Apache 2.0.
- النموذج العربي ليس نموذجاً خاصاً باللهجة اليمنية، وقد تكون دقته أقل من Whisper خصوصاً مع اللهجات أو الضوضاء.
- يلزم تنزيل النموذج أول مرة مع اتصال إنترنت ومساحة تخزين كافية؛ بعد ذلك يتم التفريغ محلياً دون اتصال أو حصص API.

## حدود التحقق
تمت إضافة الكود إلى المشروع الحالي ولم تُضمّن ملفات النماذج الكبيرة داخل APK/ZIP. لم يتم تأكيد بناء APK أو اختبار تشغيل على هاتف في بيئة العمل هذه لعدم توفر Gradle Wrapper/Gradle Android build متاحين هنا. لذلك لا يصح وصف الدمج بأنه اجتاز اختبار تشغيل حتى يتم بناء التطبيق واختباره على جهاز فعلي.
